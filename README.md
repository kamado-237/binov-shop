# 👜 Élégance Boutique — Site E-commerce Mode Femme

> Boutique en ligne moderne pour femme au Cameroun — Sacs, Chaussures & Vêtements  
> Commandes via WhatsApp | Livraison Yaoundé & Douala

---

## 🌟 Fonctionnalités

- **Catalogue produits** avec 3 catégories : Sacs, Chaussures, Vêtements
- **Base de données locale** (localStorage) — ajout/suppression d'articles sans serveur
- **Panier dynamique** avec calcul automatique du total
- **Commande WhatsApp** — message automatique envoyé au 675 075 871
- **Panneau Admin** (bouton ⚙️) pour gérer le catalogue
- **Filtres & tri** par catégorie, prix, nouveautés, promotions
- **Recherche en temps réel**
- **Design responsive** — mobile et PC
- **PWA ready** — installable sur mobile

## 🚀 Lancement

1. Cloner le repo :
   ```bash
   git clone https://github.com/VOTRE_USERNAME/elegance-boutique.git
   cd elegance-boutique
   ```

2. Ouvrir `index.html` dans votre navigateur, **ou** utiliser un serveur local :
   ```bash
   # Python
   python -m http.server 8000
   # Node.js
   npx serve .
   ```

3. Visiter `http://localhost:8000`

## 🛍️ Utilisation

### Pour les clients
- Parcourir le catalogue et filtrer par catégorie
- Cliquer sur un article pour voir les détails
- Ajouter au panier → Commander via WhatsApp

### Pour l'administrateur
- Cliquer sur le bouton ⚙️ en haut à droite
- **Ajouter** un nouvel article (nom, prix, description, emoji...)
- **Modifier** ou **Supprimer** des articles existants
- Les données sont sauvegardées automatiquement
